# Python Backend API

A production-ready REST API built with FastAPI.

## 🚀 Live Demo
https://python-backend-production-ff36.up.railway.app/docs

## 🛠 Tech Stack
- **FastAPI** — Web framework
- **SQLAlchemy** — ORM
- **JWT** — Authentication
- **Redis** — Caching
- **Celery** — Background tasks
- **Docker** — Containerization

## ✨ Features
- User registration & login
- JWT Access & Refresh tokens
- Session management
- Role-based access control (Admin/User)
- Rate limiting
- Audit logging
- Redis caching

## 🏃 Run locally
git clone https://github.com/samm0x/python-backend
cd python-backend
docker-compose up --build
